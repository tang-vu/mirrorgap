# Design guidelines

- Dark observatory aesthetic: deep navy bg, teal accent (#44d7b6), severity spectrum green→red
- Monospace for all measured values; severity always a labeled chip, never color alone
- Live/fixture badge always visible top-right; plan-gated capabilities visibly labeled, never hidden
- Radar = divergence magnitude from center; tables = auditable numbers; claims = colored by epistemic kind
- Every claim shows its evidence ids; every receipt shows its hash; every number is traceable to a CMC call
